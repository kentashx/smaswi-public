スマスイ（SmartSwim）機能全容

本書は、スマスイが提供している機能を「実装されている挙動ベース」で網羅した機能仕様サマリーです。説明のわかりやすさよりも情報密度と網羅性を優先しつつ、運用時に参照しやすい構成で整理しています。

==================================================
1. スマスイの中核的特徴（他アプリとの差別化ポイント）
==================================================

1. 競泳・フィンスイミング・筋トレを単一アプリで統合管理
・水泳（競泳）と筋トレを同一ユーザー軸で記録し、タイム、距離、負荷、努力度、コメント、画像、公開範囲を一元管理。
・泳法は競泳（FR/BK/BR/FL/IM）に加えフィンスイミング（SF/AP/FIM/BF）も対応。

2. 「練習記録」だけでなく「大会結果」「目標」「分析」「チーム運用」まで接続
・日々の練習入力 -> 目標設定 -> 大会結果入力 -> ポイント算出 -> 能力可視化 -> チーム比較、まで一連のフローをアプリ内で完結。

3. 外部記録インポートが強い
・公式競技結果サイト（result.swim.or.jp）およびマスターズ系データ（ジャンボウポイント）から候補抽出し、記録を取り込み可能。
・姓名・所属で候補検索、複数候補選択、重複解決（置換/スキップ）を伴う実務的な取り込み導線を実装。

4. チーム大会運営機能が実務寄り
・チーム内大会の作成、参加者管理、目標入力依頼、結果入力依頼、集金ステータス管理、リレー記録、写真共有までを同一機能群で提供。
・大会リンク（ディープリンク/公開リンク）で入力依頼を配布可能。

5. AIコーチが「提案生成」だけでなく「練習フィードバック」まで対応
・目標選択と距離レンジ指定から練習提案を生成。
・実施した水泳/筋トレに対して改善フィードバックを生成・保存。
・自由記述メニューの構造化（テキスト -> メニュー化）にも対応。

==================================================
2. 基本機能（認証・初期設定・共通基盤）
==================================================

1. 認証
・メール/パスワード ログイン・新規登録・パスワードリセット。
・Googleログイン、Appleログイン。
・利用規約/プライバシーポリシー同意導線を新規登録系に実装。
・メール未認証ユーザー向けガードあり。

2. オンボーディング
・言語選択（日本語/英語）。
・プロフィール初期設定。
・機能ツアー（練習入力、AI/公式練習、記録導線など）。
・完了フラグ保存後、ホームまたはチーム導線へ遷移。

3. 多言語
・日本語/英語に対応（UI文言、種目ラベルなど）。

4. アプリ制御・運営制御
・メンテナンス時の全画面ブロック表示。
・強制アップデート時のストア遷移強制導線。
・任意アップデートの通知ダイアログ。
・アカウント凍結状態の遮断表示。

==================================================
3. 練習機能（Practiceタブ）
==================================================

1. 水泳練習登録
・日付、練習時間、プール長、場所、努力度、コメントを入力。
・公開範囲を分離管理：チーム公開/全体公開/練習場所公開。
・メニューを複数行で登録（距離、本数、カテゴリ、泳法、強度、サイクル、メモ、メイン指定、使用道具）。
・テンプレートから一括展開。
・クイック距離追加、自由入力からのメニュー自動構造化（プレミアム）。
・画像添付：最大6枚、1枚8MBまで。

2. 筋トレ記録登録
・日付、場所、努力度、メモ、公開範囲を入力。
・種目ごとのセット情報（重量、回数、セット数、時間、距離、メモ、メイン指定）を登録。
・途中保存（ドラフト）対応。
・最近使った場所候補の再利用。
・画像添付：最大6枚、1枚8MBまで。

3. 練習詳細
・統計表示（距離、時間、総負荷、ラン距離/ペース、努力度など）。
・練習画像ギャラリー表示。
・練習メニュー詳細表示（道具バッジ、サイクル等）。
・編集/削除（所有者のみ）。
・テンプレート保存（所有者のみ・水泳）。

4. AIフィードバック（プレミアム）
・実施済み水泳練習/筋トレ記録に対するAI改善フィードバック生成。
・過去生成済みフィードバックの再表示。

5. 練習シェア
・月間サマリーを画像化して共有。
・練習詳細の画像シェア/テキストシェア。
・アプリリンクを含む共有文面生成。

6. 練習分析と可視化
・月間カレンダー、週/月距離、週/月負荷、累計距離/負荷を表示。
・週次距離チャート、負荷推移チャート。
・月内ランキング（距離/負荷）表示と上位詳細表示。
・総距離ランク/総負荷ランク、海の仲間ランク表示。

7. 目標セット（Goal Set）
・反復練習タイム群の入力（セット数 x 本数）。
・ペース・ばらつき・疲労落ちなど特徴量を算出。
・予測指標を提示し、履歴保存/再編集に対応。

8. 公式練習
・公式配布メニュー一覧閲覧。
・距離帯・所要時間帯のフィルタ。
・テンプレートへの保存。

==================================================
4. AIコーチ機能（プレミアム）
==================================================

1. アンケート型提案生成
・目標（複数）選択、距離レンジ、提案タイプ（水泳/筋トレ）、使用道具指定で提案生成。
・単発セッション前提のメニュー案を返却。

2. 提案履歴管理
・過去提案を履歴として保持し、再確認可能。

3. テンプレート連携
・AI提案をテンプレートとして保存可能。

4. 自由入力メニュー構造化
・テキストで書いた練習内容を構造化メニューへ変換する機能を実装。

==================================================
5. タイムライン・コミュニティ機能（Trendタブ）
==================================================

1. タイムライン表示
・全体タブ：全体公開練習を時系列表示。
・チームタブ：所属チーム内練習を表示。
・水泳/筋トレ混在のカード表示。
・ページネーション、無限スクロール、再読込対応。

2. いいね/コメント
・練習へのいいね。
・コメント投稿、返信（スレッド）、可視性設定（公開/非公開系）、通報機能。
・コメントからプロフィール遷移。

3. 可視性・プライバシー制御
・公開範囲に応じてタイムライン表示を制御。
・練習場所は公開設定に応じてマスク。

4. 画像表示
・練習に添付された画像をタイムライン経由で閲覧可能。

==================================================
6. 通知機能
==================================================

1. Push通知（FCM）
・アプリ起動時に通知許可取得、FCMトークン取得・更新保存。
・練習登録を契機に通知キューへ積み、ワーカーで配信。

2. 通知センター
・通知一覧（ページング）
・フィルタ：いいね/コメント/練習登録/運営通知。
・既読管理（全件既読、未読数管理）。

==================================================
7. チーム機能（Teamタブ）
==================================================

1. チーム参加・検索・作成
・参加チーム一覧。
・公開チーム検索（チーム名/都道府県等）。
・チーム作成（承認制設定、説明、活動拠点、アイコン）。

2. チーム参加導線
・即時参加型と承認制の両対応。
・参加申請、承認待ち確認、承認/拒否運用。
・招待メール送信。
・チーム参加リンク（公開リンク/カスタムスキーム）の解析と参加画面遷移。

3. チーム詳細
・メンバー一覧。
・チーム名/説明/活動拠点/アイコン編集。
・チーム退出。
・参加申請管理。
・入力依頼リンク（大会目標/結果、チーム参加）の生成・共有。

4. チームランキング
・今月の距離ランキング。
・今月の負荷量ランキング（部位フィルタ付き）。
・ベスト（ワールドポイント）ランキング。
・ベスト（ジャンボウポイント）ランキング。
・チーム内レコード表示。

==================================================
8. チーム大会機能
==================================================

1. 大会作成
・大会名、会場（マスター選択）、開催期間、プール長を設定。
・大会マスター（公認/マスターズ）から選択、または手動入力。
・参加者初期選択・集金管理初期値設定。

2. 大会一覧/詳細
・大会ごとの参加人数、平均ポイント表示。
・参加者管理、集金状況更新。
・目標タイム一覧、結果一覧、リレー結果一覧。
・MVP/ACE表示、目標達成率比較。

3. 大会入力導線
・目標入力依頼リンク、結果入力依頼リンクを配布。
・リンク受信ユーザーは大会コンテキスト固定状態で入力画面を起動可能。

4. リレー記録
・4泳者、区間タイム、引き継ぎリアクションを入力。
・リレー記録を保存し、個人レース記録へ区間結果を自動展開。

5. 大会メモリー（写真）
・大会写真アップロード・一覧表示（1枚8MB制限）。

==================================================
9. 記録機能（Best Time / Race Record）
==================================================

1. 記録登録
・過去の記録 / 将来の目標 を同一フォームで入力可能。
・泳法、距離、プール長、大会名/ID、会場、水着、日付、メモ、リレー、リアクション、失格、ラップを保持。
・競技カテゴリ（競泳/フィン）を扱える。

2. 目標管理
・目標一覧。
・目標に対する結果入力（達成日付き）で記録へ変換。

3. 記録一覧・詳細
・全結果表示モード/ベスト表示モードの切替。
・高度フィルタ（泳法、種目種別、距離、プール）と並び替え（日付/タイム/ポイント）。
・平均ポイント表示（ワールド/ジャンボウ）。
・詳細画面で推移グラフ、参考記録比較、ラップ/動画連携、編集/削除。

4. ポイント計算機
・タイム -> ポイント、ポイント -> タイムの双方向変換。
・ワールド記録/日本マスターズ記録を参照して計算。
・性別、年代区分、種目、リレー引き継ぎの条件を加味。

5. 能力値レーダー
・泳法ごとの能力スコアをレーダーチャート化。
・ワールドポイント内訳、リアクション分布、次バッジ目安を表示。
・シェア対応。

6. 大会結果ビュー
・大会単位で記録を束ねて閲覧。
・大会サマリー、種目別カード、比較情報を表示。

7. レース動画（プレミアム、β）
・記録への動画添付/差し替え/削除。
・比較再生導線あり。
・制限：MP4、120秒以内、25MB以下、月12本まで、署名URL配信。

==================================================
10. 外部データ取り込み
==================================================

1. 競技記録取り込み（記録タブ）
・公式（result.swim.or.jp）
  年・都道府県・大会名・姓名・所属で候補探索。
  大会検索 -> 選手検索 -> 記録候補抽出。
  athlete URL 直接指定にも対応。
・マスターズ（ジャンボウ）
  年・都道府県・氏名・チームで候補抽出。
・候補を複数選択して一括取り込み。
・類似記録の置換/スキップ解決。
・リレー時はチーム情報と個人区間情報を保持して取り込み。

2. CSV移行（プロフィール）
・スイムペリアCSVの解析・プレビュー。
・取り込み対象を行単位で選択。
・不正行の理由表示。
・水泳練習/筋トレ/レースの一括移行。

11. プロフィール・個人機能（Profileタブ）
==================================================

1. プロフィール表示/編集
・ニックネーム、性別、生年月日、身長、体重、アバター。
・筋トレ重量増減幅（+/-刻み）設定。
・通知設定導線。

2. 保有水着管理
・水着マスター選択またはカスタム名称で登録。
・保有水着の一覧・メモ参照。

3. バッジ・ランク
・ワールドポイントに基づくユーザーバッジ表示。
・距離ランク、負荷ランク表示。

4. メダル図鑑（ゲーミフィケーション）
・二部練王、三部練王、5km突破王、皆勤王、コメント王、遠征王、登録王、コミュ力王、装備王、水着王、BIG3王、いいね王、目標達成王、継続王などを進捗付きで表示。
・達成お祝い表示、メダル共有対応。

5. その他
・アプリ更新履歴表示。
・フィードバックフォーム/規約/プライバシー導線。
・ログアウト。

==================================================
12. プレミアムプラン機能と無料制限
==================================================

1. 主なプレミアム特典
・参加チーム数制限解除。
・テンプレート登録数制限解除。
・ランキング詳細表示拡張。
・水着/会場/体重など分析の詳細表示。
・AIコーチ（提案、構造化、フィードバック）。
・レース動画添付/比較（β）。
・広告非表示。

2. 代表的な無料制限
・参加チーム数：1チームまで。
・テンプレート：3件までフル解放（それ以上はロック）。
・一部ランキングの下位表示をロック。

3. 課金運用
・月額サブスク、7日トライアル、復元導線、猶予期間状態を扱う。

==================================================
13. 運用・品質補助機能（ユーザー価値に直結するもの）
==================================================

1. 通信エラー時の再試行UI、ネットワーク障害向け表示。
2. リアルタイム更新の再接続制御。
3. バージョン強制/任意更新制御。
4. Sentry/Clarity等を用いた品質監視（環境別制御）。


以上が、現在のスマスイ実装で確認できる機能全容です。
